# Competitor Research - Digital Signage Dashboards

> Análisis de competidores para el rediseño del dashboard de Upper DS

---

## Competitors Analyzed

### 1. Yodeck

**Website:** yodeck.com

**Key Features:**

- Dashboard centralizado con vista rápida de estado de pantallas
- Drag-and-drop para archivos multimedia
- Multi-zone layouts (pantalla dividida)
- Scheduling intuitivo por tiempo/día
- Stock photos/videos incluidos
- Hardware gratuito en planes anuales

**UI Patterns:**

- Sidebar colapsable
- Cards para contenido
- Preview en tiempo real
- Status indicators (online/offline)

---

### 2. ScreenCloud

**Website:** screencloud.com

**Key Features:**

- Gestión remota centralizada
- Integración con BI tools (Power BI, Tableau, Grafana)
- SSO y 2FA
- Role-based access control
- Dashboard sharing seguro

**UI Patterns:**

- Drag-and-drop content editor
- Cloud storage integration (Google Drive, Dropbox)
- Real-time monitoring
- Proof of play logs

---

### 3. NoviSign

**Website:** novisign.com

**Key Features:**

- Widgets drag-and-drop (weather, clock, social media)
- Power BI y Tableau integration
- Monitoreo y reportes en tiempo real
- Templates creativos gratuitos

**UI Patterns:**

- Dashboard de monitoreo
- Gestión de usuarios y roles
- Playlist scheduling
- Offline playback support

---

### 4. OptiSigns

**Website:** optisigns.com

**Key Features:**

- Templates variados
- Google Slides integration
- Social media feeds
- Fire TV Stick support
- Permisos granulares de usuario/contenido

**UI Patterns:**

- Central management portal
- Scheduling avanzado
- RSS feeds integration

---

### 5. Rise Vision

**Website:** risevision.com

**Key Features:**

- Enfoque educación (escuelas)
- Templates educativos
- Scheduling robusto
- Integración con Google Drive, OneDrive, Canva

---

### 6. Signagelive

**Website:** signagelive.com

**Key Features:**

- Enterprise-grade security (ISO 27001)
- SSO y 2FA
- Permisos granulares escalables
- BI tools integration (Power BI, Tableau)

## Competitive Advantages to Maintain

1. **Pantallas de Vuelos** - Servicio especializado único
2. **Pantallas de Promociones** - Sistema robusto de eventos
3. **Multi-tenancy** - Modelo empresa funcionando
4. **Precios competitivos** - Plan gratuito

---

## Areas to Improve vs Competitors

1. **UI/UX moderna** - Dashboard actual anticuado
2. **Dark mode** - No existe actualmente
3. **Mobile responsive** - Parcial
4. **Onboarding** - Mejorar para B2C
5. **Self-service** - Automatizar plan gratuito
